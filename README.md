# Maruf's Tech & AI Blog

Personal blog focused on technology, artificial intelligence, and digital culture.

Live site: https://maruf.moolvylabs.org/

## About

This repository contains the source code for my personal blog. The site is built as a lightweight static website and is designed for quick publishing, easy maintenance, and a clean reading experience.

The content is written in English and Russian, and the layout supports both light and dark modes.

## Stack

- HTML
- CSS
- JavaScript
- Static hosting
